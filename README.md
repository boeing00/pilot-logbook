# Pilot Logbook

Digital flight logbook for tracking hours, routes, landings, and instrument time.

## Features

- Log flights with aircraft, airports, time categories, landings, and remarks
- Running totals (total time, PIC, night, cross country, landings)
- Search and edit entries
- Export to CSV
- Data stored locally in the browser (`localStorage`)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
